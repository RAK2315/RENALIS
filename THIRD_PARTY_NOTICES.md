# Third-party data and dependencies

HEMOBP v3: Wu, C.-J. (2018). DOI [10.6084/m9.figshare.6260654.v3](https://doi.org/10.6084/m9.figshare.6260654.v3). Dataset license [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Dataset files are downloaded unchanged into ignored local data storage; transformations are described in `scripts/hemo.py`. The project code license does not apply to those data files.

Data paper: Lin, C.-J., Chen, Y.-Y., Pan, C.-F., et al. Dataset supporting blood pressure prediction for the management of chronic hemodialysis. Scientific Data 6, 313 (2019). [DOI](https://doi.org/10.1038/s41597-019-0319-8).

Clinical context: Intradialytic Hypotension and Cardiac Arrhythmias in Patients Undergoing Maintenance Hemodialysis: Results from the Monitoring in Dialysis Study. [Primary publication](https://pubmed.ncbi.nlm.nih.gov/32381584/).

React, React DOM, Vite, Recharts, Lucide and other JavaScript dependencies retain their package licenses. Python dependencies retain their respective licenses. Google Fonts serves DM Sans and Fraunces; local/system font fallbacks are available when the fonts cannot load. No clinical dataset is included in the app bundle.

Optional video narration uses [Kokoro-82M v1.0](https://huggingface.co/hexgrad/Kokoro-82M), licensed under [Apache-2.0](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/LICENSE), through the MIT-licensed [kokoro-onnx runtime](https://github.com/thewh1teagle/kokoro-onnx). Model/voice files are downloaded from the runtime maintainer's model-files-v1.1 release into ignored local artifact storage. The default voice is af_heart; optional samples also use af_bella, bf_emma, and am_fenrir. Download URLs and SHA-256 file digests are retained in artifacts/video/voice-provenance.json. No source speaker recording or paid speech API is used. The film's music is generated by the project's own oscillator code. Optional independent speech transcription uses faster-whisper and the tiny.en Whisper model, each under its respective MIT license.
